# Kinseat 0.3.21

**Sécurité des places, Client Linux utilisable sur Debian 12 / Ubuntu 22.04 et plus récents, et lancement du flux plus fiable.**

## Client

- Si le premier lancement du flux échoue, le Client le relance automatiquement une fois.
- Le journal Windows du Client ne répète plus « crochet installé » toutes les 2 secondes.

## Client Linux

- Le paquet `.deb` est compatible **Debian 12 et Ubuntu 22.04 et plus récents** (glibc 2.35).
- Les dépendances graphiques sont déclarées dans le paquet : plus de plantage au lancement quand `libxkbcommon-x11` manque.
- Si Moonlight est absent, un message visible l'indique au lieu d'un clic sans effet.
- Kinseat utilise son propre profil Moonlight, séparé de celui de l'utilisateur.
- L'appairage est corrigé sous Debian 12 avec Moonlight en AppImage (conflit avec OpenSSL) ; le fichier `.AppImage` est extrait automatiquement une seule fois.

## Places : sécurité

Les comptes de place gérés par Kinseat ne peuvent plus, depuis leur session :
- ouvrir les Paramètres, le Panneau de configuration ni regedit ;
- modifier les réglages réseau ;
- lancer les outils système (commande d'arrêt, PowerShell, mmc…) ;
- arrêter ou redémarrer le PC par les menus.

Le Gestionnaire des tâches reste **volontairement autorisé**, pour fermer un jeu figé.

Ces stratégies sont appliquées à toutes les places gérées au démarrage du service et avant chaque session, avec un journal par place. Détails : [docs/kinseat/securite-places.md](../kinseat/securite-places.md).

## Limites connues

- Un compte ajouté comme place sans avoir été créé par Kinseat n'est pas protégé (journal « compte non géré »).
- L'arrêt par la commande tapée dans une console n'est pas encore bloqué au niveau de la machine.
- Les raccourcis du bureau public restent visibles pour les joueurs.

## Installation

| Fichier | Où l'installer |
|---|---|
| `Kinseat-Host-Setup-0.3.21.exe` | PC de jeu Windows 10/11 x64 (administrateur) |
| `Kinseat-Client-Setup-0.3.21.exe` | appareil du joueur, Windows x64 (Moonlight inclus) |
| `kinseat-client_0.3.21_amd64.deb` | appareil du joueur, Debian 12 / Ubuntu 22.04 et plus récents |
| `SHA256SUMS` | empreintes SHA-256 de tous les fichiers |

Installez par-dessus la version précédente, sans désinstaller.

## Clients expérimentaux

Les Clients **Windows ARM64**, **Linux x64** (`.deb`, `.tar.gz`) et **macOS** (Apple Silicon, Intel) sont fournis à titre expérimental : ils sont construits automatiquement mais **n'ont pas encore été testés** sur tous les systèmes. Le Client Windows x64 reste la version recommandée.
