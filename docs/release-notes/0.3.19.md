# Kinseat 0.3.19

**Correctif de la 0.3.18 : utilisez cette version pour toute nouvelle installation.**

L'installateur Hôte 0.3.18 avait été construit sans **Apollo** (le serveur de streaming) ni **HidHide** (l'isolation des manettes). Une mise à jour par-dessus une version précédente fonctionnait, car ces composants étaient déjà installés, mais une **première installation** de l'Hôte 0.3.18 ne pouvait pas diffuser. La 0.3.19 les réintègre, et la construction de l'installateur échoue désormais si l'un d'eux manque.

Autres corrections :
- les accents de l'installateur Hôte s'affichent correctement (« Kinseat Hôte » dans les Paramètres Windows, messages de progression) ;
- l'option d'isolation Steam (désactivée par défaut) pointe vers le bon dossier d'installation `C:\Program Files\Kinseat` ;
- numéro de version 0.3.19 sur l'Hôte et les Clients.

Le contenu fonctionnel de la 0.3.18 (refonte de l'interface, corrections de sécurité et de stabilité) est inchangé.

## Installation

| Fichier | Où l'installer |
|---|---|
| `Kinseat-Host-Setup-0.3.19.exe` | PC de jeu Windows 10/11 x64 (administrateur) |
| `Kinseat-Client-Setup-0.3.19.exe` | appareil du joueur, Windows x64 (Moonlight inclus) |
| `SHA256SUMS` | empreintes SHA-256 de tous les fichiers |

Installez par-dessus la version précédente, sans désinstaller.

## Clients expérimentaux

Les Clients **Windows ARM64**, **Linux x64** (`.deb`, `.tar.gz`) et **macOS** (Apple Silicon, Intel) sont fournis à titre expérimental : ils sont construits automatiquement mais **n'ont pas encore été testés** sur ces systèmes. Le Client Windows x64 reste la version recommandée.
